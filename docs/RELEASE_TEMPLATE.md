## Installeur TV Launcher

Télécharge **Installeur-TV-Launcher.zip**, décompresse-le et lance `Installeur-TV-Launcher.exe` (Windows 10/11).

> Windows peut afficher « Windows a protégé votre ordinateur » car l'exécutable n'est pas signé : *Informations complémentaires* › *Exécuter quand même*. Tu peux vérifier l'intégrité du zip avec `SHA256SUMS.txt` (`certutil -hashfile Installeur-TV-Launcher.zip SHA256`).

**Compatibilité** : TV et box Android TV / Google TV sous Android 8.0+. Testé uniquement sur un Philips 55OLED810. Incompatible : Samsung (Tizen), LG (webOS), Roku, Apple TV, Fire TV, TV sous VIDAA ou Titan OS.

**À savoir** : les suggestions des applis de streaming ouvrent l'application (pas la fiche du film ou de la série), sauf YouTube. Selon le modèle, le bouton Paramètres de la télécommande peut ne plus fonctionner (utilise l'icône ⚙ de l'accueil).

Le code est compilé automatiquement par GitHub Actions à partir des sources de ce dépôt.
