Installeur TV Launcher

Bienvenue

Cet assistant installe le launcher personnalisé sur ta TV Android TV / Google TV : il se connecte à la TV, la sauvegarde, la nettoie, prépare le projet avec tes clés, compile l'application puis l'installe. Prévois 30 à 60 minutes, dont 10 à 20 pour la première compilation.

Avant de commencer, il y a 5 choses à préparer. Ouvre chaque bloc, fais ce qui est indiqué, puis coche la case en bas.
Liste de compatibilité
✓ Prévu pour
  • TV et box Android TV / Google TV, Android 8.0 ou plus
  • Philips (Android TV), Sony Bravia, TCL, Hisense (Android TV), Xiaomi Mi Box, Nvidia Shield, Chromecast avec Google TV…
✗ Incompatible
  • Samsung (Tizen), LG (webOS)
  • Roku, Apple TV
  • Fire TV d'Amazon (écran d'accueil non remplaçable)
  • Téléviseurs sous VIDAA ou Titan OS (certains Philips récents)
Testé uniquement sur un Philips 55OLED810. Pour les autres modèles compatibles sur le papier, tout n'est pas garanti : la touche Paramètres de la télécommande, le nettoyage et la définition du launcher par défaut varient selon les marques. L'étape 3 vérifie ta TV en direct.
1. Activer le mode développeur sur la TV et noter son adresse IP
  1. Sur la TV : Paramètres › Préférences de l'appareil › À propos.
  2. Appuie 7 fois sur OK sur la ligne « Build » (ou « Numéro de build »). Un message indique que tu es développeur.
  3. Reviens en arrière : Préférences de l'appareil › Options pour les développeurs.
  4. Active « Débogage USB » (parfois appelé « Débogage ADB »), puis « Débogage sans fil » (ou « Débogage réseau »).
  5. Ouvre l'écran du Débogage sans fil : il affiche « Adresse IP et port », par exemple 192.168.1.25:37891. Note l'adresse IP et le port.
  6. Si la TV propose « Associer l'appareil avec un code », ouvre cet écran : elle affiche une adresse avec un port d'association et un code à 6 chiffres. Tu les saisiras à l'étape suivante. Ils changent à chaque ouverture.
La TV et ce PC doivent être sur le même réseau (box ou routeur).
2. Installer Android Studio (il fournit Java et le SDK pour compiler)
  1. Télécharge Android Studio : developer.android.com/studio (gratuit, environ 1 Go).
  2. Installe-le avec les options par défaut.
  3. Lance-le une première fois et laisse l'assistant terminer (il télécharge le SDK Android). Tu peux ensuite le fermer : l'installeur s'occupe du reste.

L'installeur n'a pas besoin que tu ouvres le projet dans Android Studio : il utilise son Java et son SDK en arrière-plan.

3. Créer une clé API OpenWeather (météo actuelle)
  1. Crée un compte gratuit : home.openweathermap.org/users/sign_up et confirme ton e-mail.
  2. Ouvre home.openweathermap.org/api_keys : une clé nommée « Default » existe déjà (ou crée-en une avec un nom au choix).
  3. Copie la clé (32 caractères).
Une clé neuve peut mettre jusqu'à 2 heures à fonctionner. Si le test échoue à l'étape suivante, continue quand même et réessaie plus tard : la clé sera valide au moment de l'utilisation.
4. Créer une clé API TMDB (affiches, films et séries populaires)
  1. Crée un compte gratuit : themoviedb.org/signup et confirme ton e-mail.
  2. Ouvre themoviedb.org/settings/api et clique sur « Créer » (ou « Request an API key »), choisis « Developer » et accepte les conditions.
  3. Remplis le formulaire : nom d'application « TV Launcher perso », URL : n'importe quelle adresse valide (par exemple https://example.com), résumé : « Launcher personnel pour ma TV Android, usage privé et non commercial, affiche les films et séries populaires ».
  4. Copie la « Clé d'API » (32 caractères hexadécimaux). Pas le « Jeton d'accès en lecture » (beaucoup plus long).
5. Créer une clé API YouTube Data (vidéos tendances)
  1. Va sur console.cloud.google.com avec ton compte Google et accepte les conditions.
  2. En haut, clique sur le sélecteur de projet, puis « Nouveau projet » (nom : « TV Launcher ») et valide.
  3. Menu ☰ › API et services › Bibliothèque. Cherche « YouTube Data API v3 », ouvre-la et clique sur « Activer ».
  4. Menu ☰ › API et services › Identifiants › « Créer des identifiants » › « Clé API ».
  5. Copie la clé affichée (elle commence par AIza). Tu peux la restreindre à « YouTube Data API v3 » (recommandé, facultatif).

Gratuit : le quota quotidien (10 000 unités) est très largement suffisant pour un usage personnel.

À savoir avant d'installer
  • Les suggestions ouvrent l'application (Prime Video, Apple TV, Canal+, Disney+), pas la page du film ou de la série. Seul YouTube ouvre directement la vidéo choisie.
  • Selon le modèle de TV, le bouton Paramètres de la télécommande peut ne plus fonctionner avec ce launcher (c'est la TV qui le garde pour elle). Utilise alors l'icône ⚙ en haut à droite de l'écran d'accueil.
Les suggestions « populaires en ce moment » et les sorties Canal+ sont réglées sur la France.

Connexion à la TV

L'installeur télécharge au besoin adb (l'outil officiel de Google) et se connecte à ta TV.

Garde un œil sur la TV : une fenêtre « Autoriser le débogage USB ? » va apparaître. Coche « Toujours autoriser » et valide.

Sauvegarde et nettoyage

D'abord une sauvegarde de l'état de la TV, ensuite la désactivation des services de publicité, de télémétrie et de recommandations.

1. Sauvegarder la TV

Enregistre la liste des applications, celles déjà désactivées, les réglages Android et le launcher d'origine dans un dossier de l'installeur. Ce n'est pas une copie des applications : le nettoyage ne supprime rien, il désactive.

2. Nettoyer
Tout est réversible (bouton « Tout restaurer »). Seuls les paquets présents sur ta TV sont proposés. La liste est issue de pratiques courantes sur Android TV, je ne peux pas garantir qu'elle couvre toutes les marques : relis-la et décoche ce que tu veux garder.
Connecte-toi d'abord.

C'est installé !

Appuie sur le bouton Accueil de ta télécommande. Si Android demande quel écran d'accueil utiliser, choisis « TV Launcher » puis « Toujours ».

Pour revenir en arrière : étape 4 › « Tout restaurer », et désinstalle « TV Launcher » dans Réglages › Applications.
